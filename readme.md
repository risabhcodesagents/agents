## This is the repo for all agents from my instagram channel
Instagram channel link: [@risabh.codes.agents](https://www.instagram.com/risabh.codes.agents/)

## Current Agents:

1. helloWorldAgent: A hello world agent, that has a greeting node in state graph that modifies the message state variable and in end, presents the output.

2. greetingAgent: Using llm (qwen2.5-vl) running with llama.cpp, I have made a very simple greeting agents, where user will provide a name and llm will process it and return a warm greeting.

3. conditionalAgent: A simple agent demonstrating the conditional edges used in langraph.
